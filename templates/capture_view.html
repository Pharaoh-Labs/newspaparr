Paste the NYT-S cookie for {{ account.name }} (NYT)

  1. In your own browser, go to nytimes.com and log in with this account.
  2. Open developer tools:
    • Safari: enable the Develop menu (Settings → Advanced → "Show features for web developers"), then Develop → Show Web Inspector → Storage tab → Cookies → nytimes.com.
    • Chrome/Edge: press ⌘⌥I (or F12), then Application tab → Cookies → https://www.nytimes.com.
    • Firefox: press ⌘⌥I, then Storage tab → Cookies.
  3. Find the cookie named NYT-S and copy its Value (double-click the value cell, select all, copy).
  4. Paste it below and click Save cookies.
Sessions typically last ~30 days. Re-paste when renewals start failing.
